# AnnaNails — лендинг мастера маникюра на дому

Одностраничный сайт для частного мастера маникюра и педикюра с выездом к клиенту.
Главная задача — конвертировать посетителя в запись на первый визит со скидкой 50%.

![Превью лендинга](docs/preview.png)

## Возможности

**Продающая часть**
- Хиро-блок с оффером «скидка 50% на первый визит», реальным фото работы и плавающими элементами
- Бегущая строка с преимуществами
- Промо-блок с живым таймером акции (48 часов) и промокодом `FIRST50`, который копируется в буфер по клику
- Прайс из 6 услуг: старая цена зачёркнута, рядом — цена со скидкой
- Портфолио из реальных работ с лайтбоксом (листание стрелками, `Esc`, клик по фону)
- Блок «Обо мне» с фото мастера, стажем, рейтингом и гарантией
- Отзывы, FAQ-аккордеон, финальный CTA со счётчиком свободных слотов
- Липкая панель с ценой и кнопкой записи на мобильных

**Форма записи**
- Поля: имя, телефон (автомаска `+7 (___) ___-__-__`), услуга, дата, время, адрес
- Дата не может быть раньше сегодняшней
- Валидация с подсказками под каждым полем
- Автоматический пересчёт цены и старой цены при выборе услуги
- Кнопки «Выбрать» в прайсе сами подставляют услугу в форму
- Отправка заявки в **Telegram-бот** и резервное сохранение в `localStorage`
- Подтверждение с именем, датой и временем визита

**Качество**
- Lighthouse: **Accessibility 100 / Best Practices 100 / SEO 100**
- Адаптив от 360px: 4 → 2 → 1 колонка
- Семантическая разметка, `<main>`, `alt` у фото, корректный порядок заголовков
- Учёт `prefers-reduced-motion`
- Без фреймворков и сборки — чистые HTML, CSS, JS

## Быстрый старт

Просто откройте `index.html` в браузере. Для корректной работы `fetch` (отправка заявок)
лучше поднять локальный сервер:

```bash
# Python
python -m http.server 8099

# или Node.js
npx serve .
```

Затем откройте `http://localhost:8099`.

## Подключение заявок в Telegram

1. Скопируйте шаблон конфига:

   ```bash
   cp config.example.js config.js
   ```

2. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и логин → получите **токен**.
3. Напишите своему боту любое сообщение (без этого он не сможет вам писать).
4. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и скопируйте `"chat":{"id": ...}`.
5. Вставьте оба значения в `config.js`:

   ```js
   window.ANNA_CONFIG = {
     TELEGRAM_BOT_TOKEN: '7123456789:AAH...',
     TELEGRAM_CHAT_ID: '123456789',
     BOT_TITLE: 'AnnaNails — новая заявка'
   };
   ```

Заявка придёт в чат готовым сообщением:

```
🔔 AnnaNails — новая заявка

Имя: Марина
Телефон: +79001112233
Услуга: Маникюр + гель-лак — 1 100 ₽
Дата: 30.10.2026, 12:30
Адрес: ул. Ленина, 12
Промокод: FIRST50 — скидка 50%
К оплате: 1100 ₽
```

Пока ключи не заполнены, форма продолжает работать: заявка сохраняется в браузере
и показывается нейтральное подтверждение.

> **Безопасность.** Токен бота лежит в клиентском JS и виден в исходниках страницы.
> Отправлять сообщения злоумышленник сможет только в ваш `chat_id`, но для полной
> защиты вынесите отправку на сервер (serverless-функция, Google Apps Script) —
> тогда токен останется на бэкенде.

## Кастомизация

| Что менять | Где |
|---|---|
| Цены и состав услуг | карточки в `index.html` + объект `PRICES` и `<option>` в `script.js` |
| Телефон, Telegram, WhatsApp | шапка, блок записи и футер в `index.html` |
| Фото работ | `img/` + `src` и `alt` в блоке `#gallery` |
| Фото мастера | `img/master_anna.jpeg` |
| Текст акции и промокод | секции `.promo` и `#booking` |
| Длительность акции | `script.js`, блок таймера (по умолчанию 48 часов) |
| Палитра и шрифты | CSS-переменные в `:root` (`--rose`, `--rose-deep`, `--font`, `--display`) |

## Технологии

- HTML5, CSS3 (Grid, Flexbox, `clamp()`, CSS-переменные, `aspect-ratio`)
- Vanilla JavaScript (ES2017+): `IntersectionObserver`, `fetch`, `AbortController`, `localStorage`
- Google Fonts: Cormorant Garamond + Manrope
- Telegram Bot API
